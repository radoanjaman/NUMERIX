What each folder does
- core/: Common mathematical utilities, input parsing, validation, error calculation and result formatting.
- algorithms/: All numerical algorithms. No GUI code should be placed here.
- gui/: Every screen, button, input form, navigation element and result table.
- visualization/: All mathematical graphs.
- services/: Connects GUI requests to algorithms and manages comparisons.
- storage/: Saves previous calculations.
- tests/: Tests algorithms against known answers and reference calculations.
- docs/: User documentation and mathematical explanations.
